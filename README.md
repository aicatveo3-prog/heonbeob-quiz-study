# 헌법 OX 퀴즈 (heonbeob-quiz-study)

헌법을 **주제별 OX 퀴즈**로 학습하는 정적 웹앱입니다. 답을 고르면 즉시 정답·해설이 뜨고, 파트별 **이론 정리**와 **최종 암기 체크리스트**를 함께 제공합니다.

**▶ 바로 풀기: https://aicatveo3-prog.github.io/heonbeob-quiz-study/**

> 한국사 OX 퀴즈 앱(`history-quiz-study`)의 앱 프레임워크·작업 표준을 그대로 가져와 헌법용으로 새로 세팅한 프로젝트입니다. 앱 코드·데이터 형식은 동일하고 도메인만 헌법으로 바뀌었습니다.

## 구성

- 홈(챕터 목록) → 목차(파트) → 퀴즈 → 결과 흐름. 챕터 데이터는 카드 탭 시 지연 로딩.
- 각 문항: 기출·핵심 개념을 옳게 서술한 ⭕ 문항 + 핵심어를 바꾼 ❌ 변형 문항을 짝으로 구성(파트별 O/X 비율 5:5 근접, 같은 정답 4연속 없음).
- 파트별 **이론 정리** 패널(섹션·표·⚠️ 함정 체크 콜아웃) — ON/OFF 토글, 상태는 `localStorage` 저장.
- 파트 목록 상단 ⭐ 카드에서 **최종 암기 체크리스트** — 항목 탭 시 암기 체크(localStorage), 진행률 표시.

## 헌법 분야 구성 (권장 3분야)

- **헌법총론** — 헌법의 의의·특성, 헌법의 제정·개정, 대한민국 헌정사, 헌법의 기본원리, 정당·선거제도, 기본제도
- **기본권론** — 기본권 총론, 인간의 존엄과 가치, 평등권, 자유권, 참정권, 청구권, 사회권, 국민의 의무
- **통치구조론** — 통치구조의 원리, 국회, 대통령·정부, 법원, 헌법재판소, 선거관리·지방자치

편(`hb01`~`hbNN`)의 개수·경계는 자료를 받아 총론 → 기본권 → 통치구조 순서로 확정합니다.

## 현재 수록 (헌법 495문항 · 3개 편)

- 제1편 헌법총론 — 88문항 (전문·문화국가·경제질서·국적·정당·영토/통일·법치주의·선거제도·헌정사)
- 제2편 기본권론 — 166문항 (종교·생명/자기결정·영장·청구권·직업·재산권·평등권·사생활·집회·기본권총론·행복추구권·알권리·통신·진술거부권·교육/사학·거주이전·참정권)
- 제3편 통치구조론 — 241문항 (국회·대통령/정부·법원·행정입법·지방자치·헌법재판·국정통제/재정·선거관리위원회·감사원)

**지방직 7급 헌법 4회분**(2025 Ⓑ·2024 Ⓐ·2023 Ⓑ·2022 A책형, 각 20문항)을 선지 단위로 분해해 3개 편에 분산 반영했습니다. 기출 논점 문항에는 `지방직 7급 2025`~`2022` 출처 뱃지가 붙고, 여러 해에 반복 출제된 논점에는 **"N회 출제" 빈출 뱃지**가 함께 붙습니다. 앱 상단 **🏅 기출만 보기** 토글로 골라 볼 수 있으며, 앞으로 회차·자료가 늘면 같은 편에 누적됩니다.

## 개발

- 정적 사이트: `app/index.html`, `app.js`, `chapters.js`, `quizdata-<id>.js`.
- 새 편 추가: `app/quizdata-hbNN.js` 생성 → `app/chapters.js`의 `CHAPTER_LIST`에 `{ id, num, title, file, count }` 추가 → `app/index.html`의 `ASSET_VER` 갱신.
- 배포: GitHub Pages가 `main` 브랜치를 자동 배포.
- 작업 표준(퀴즈 변환·이론정리·체크리스트·기출 반영): 루트 `CLAUDE.md` 참고.
