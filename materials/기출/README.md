# 헌법 기출 원본 자료

헌법 기출문제 원본을 시험·회차별로 보관하는 폴더다. 기출 반영("기출 NN 해줘", 루트 `CLAUDE.md` 표준 4) 시 근거·검증 자료로 쓴다.

- `<시험명>_<연도·회차>_정답표.txt` — 공식 정답표 + 분야 배정
- `<시험명>_<연도·회차>_원문추출.txt` 또는 `_원문메모.txt` — 문제 원문

예) `변호사시험_제14회_정답표.txt`, `경찰_2024-1차_원문추출.txt`

> 현재 보관: 국가직 7급 2018~2025(8회), 지방직 7급 2020~2025(6회)의 회차별 정답표·원문. 새 시험지를 받으면 여기에 원본을 먼저 저장한 뒤 반영한다.
